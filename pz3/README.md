# Практическая работа №3 — Визуализация алгоритмов

Интерактивное приложение на **Python + PyGame** для пошаговой визуализации:
- Bubble Sort (пузырьковая сортировка)
- Selection Sort (сортировка выбором)
- Binary Search (бинарный поиск)

## Запуск
1. Установить PyGame:
   pip install pygame
2. Запустить:
   python main.py

## Управление
| Клавиша | Действие |
|---------|----------|
| 1 | Bubble Sort |
| 2 | Selection Sort |
| 3 | Binary Search |
| SPACE | Старт / Пауза |
| N | Следующий шаг |
| R | Новый массив |
| T | Ввести target (в режиме Binary Search) |
| F | Случайный target |
| Esc | Выход |

## Структура
- `main.py` — окно, event loop, переключение режимов
- `algorithms.py` — алгоритмы в виде генераторов (без pygame)
- `visualizer.py` — отрисовка массива, статистики, легенды
- `settings.py` — цвета, размеры, константы

## Особенности реализации
- Алгоритмы реализованы через `yield` (пошагово, без сохранения всех кадров)
- Bubble Sort с оптимизацией раннего завершения
- Бинарный поиск работает только по отсортированному массиву
- `time.sleep` не используется — управление через delta time + таймер шага
- `algorithms.py` не импортирует pygame
